# 🔗 URL Shortener

A simple URL shortener built using Python and Flask. It allows users to enter a long URL and get a shortened version that redirects to the original link.

---

## 🚀 Features

- Generate unique, shortened URLs
- Store URL mappings in memory
- Redirect users from shortened URLs to original ones
- Minimal and beginner-friendly code structure

---

## 📁 Project Structure
url_shortener/
├── main.py # Flask application
├── templates/
│ └── index.html # HTML form to input long URL

---

## ⚙️ Requirements

- Python 3.7+
- Flask
